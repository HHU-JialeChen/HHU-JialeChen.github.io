Few-Shot Class-Incremental Learning (FS-CIL) enables models to rapidly acquire new categories from scarce samples while preserving knowledge of previously learned categories. The core challenge of FS-CIL is balancing the model's plasticity for  new-class learning and  stability for old-class retaining. Our work draws functional inspiration from the hippocampal-neocortical memory mechanism of the human brain. The mechanism includes rapid new-memory encoding in the hippocampus, long-term knowledge storage in the neocortex and sleep-driven replay that distinguishes old and new memories. We propose a brain-inspired synergistic-memory prompt tuning framework built on pre-trained vision-language models. Specifically, a multi-level prompt tuning module mimics the hippocampus to realize rapid few-shot adaptation to new categories. Meanwhile, a dynamic prototype library simulates the neocortex to condense and stably preserve learned knowledge. Furthermore, in order to emulate the interaction between hippocampus and neocortex, a memory-driven calibration module is proposed. This module further optimizes the memory space management by applying additional perturbation and metric constraints to the relationship between old and new memories. Extensive experiments conducted on miniImageNet, CIFAR100 and CUB200 validate the effectiveness of the proposed method, demonstrating an excellent balance between new knowledge acquisition and memory retention. Code is available in https://github.com/HHU-JialeChen/BSPT.git.
